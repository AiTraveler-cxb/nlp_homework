# 渐进式 Skill Harness — Context 占用对比

## 测试环境

- Python 3.14
- 无外部依赖（仅使用 Python 标准库）
- Token 估算为教学简化版：中文字符 + 英文单词各计 1 token

## 对比结果

| Query | 渐进式加载 (tokens) | 全量加载 (tokens) | 节省 (tokens) | 节省比例 |
|------|-------------------|------------------|-------------|---------|
| 北京今天天气怎么样？ | 218 | 521 | 303 | 58.2% |
| 帮我算一下 (15 + 23) * 4 等于多少 | 197 | 524 | 327 | 62.4% |
| 帮我写一份周报 | 282 | 519 | 237 | 45.7% |
| **总计** | **697** | **1564** | **867** | **55.4%** |

## 结论

在本次 3 个 Skill 的演示场景中，渐进式加载模式相比全量加载模式：

- Context 总占用从 1564 tokens 降至 697 tokens。
- 平均节省约 **55.4%** 的 Context 占用。
- 随着 Skill 数量增加，全量加载会线性膨胀，而渐进式加载仅与命中 Skill 的大小相关。
